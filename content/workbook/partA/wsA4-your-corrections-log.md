# WS A4. Your corrections log

A running list of the corrections that must stick, with the first five filled in and a rule for when a correction graduates into memory or a skill. Twenty minutes to start; two minutes a week after.

## Why this matters

Every correction you keep is one you never make again. The keeping is the part people skip. They correct the tool in the moment, it holds for the conversation, and the next conversation makes the same mistake, because a conversation is a room and nothing follows you out. The log is where the correction goes so it survives the room.

It's a file. One line per correction: what it did, what it should do instead, the date. Nothing else. After a month you'll have twenty lines and you'll notice three things about them: the same correction appears more than once, some of them are about you regardless of the task, and some are about one kind of work. That's the sorting from Worksheet 0.4, and the log is where it happens.

Nobody sets out to build a list. They set out to fix one sentence in one draft. The list gets long anyway, and every item on it started as a second message.

## An example

*An illustration, not a real person.* The first entries in a nonprofit director's log might look like this.

| Date | What it did | What it should do | Where it went |
|---|---|---|---|
| March | Opened a donor letter with "I hope this finds you well" | Never. Open on the thing we did with their money. | Memory, then the writing skill |
| April | Called our programs "initiatives" | We run programs. Use the word we use. | Memory |
| May | Wrote "over 500 families served" | The real number, with the year: "612 families in 2025." | Memory, and the grant skill |
| June | Three exclamation points in a board memo | None, ever. | Memory, writing skill |
| August | Invented a quote from a board member | Never invent a quote, a number, or a meeting. Leave a bracket. | Memory, every skill |
| September | Named a donor who asked to be anonymous | No donor names in anything unless I've confirmed consent. | The grant and donor skills |

The last column is the point. A correction that's true everywhere went to memory. A correction about one kind of work went to that skill. The ones that cost the most (the invented quote, the named donor) became lines the fact-check pass looks for, so a machine catches them first.

## Your turn

1. **Start the file.** Create `logs/corrections.md` with this header:
   ```
   # Corrections
   | Date | What it did | What it should do | Where it went |
   |---|---|---|---|
   ```

2. **Fill in the first five.** Think back over your conversations so far. What have you corrected more than once? Write five rows. Leave the last column blank for now.
   - _____
   - _____
   - _____
   - _____
   - _____

3. **Sort them.** For each row, ask the three questions from Worksheet 0.4: true about me everywhere (memory), about one kind of task (a skill, Part B), or true only in one project (that project's instructions)? Fill in the last column with where it should go, even if you haven't put it there yet.

4. **Move the first one.** Take the correction that's bitten you most. If it's a memory item, give it to the tool now ("Remember: never..."). If it's a skill item, keep it; B1 will have a Rules section waiting for it.

5. **Set the habit.** Finish this sentence and put it where you'll see it: "When I correct the tool and I've corrected it before, I ______ within ______."
   _____

*How to: nothing to install; the log is an .md file in your folder (Worksheet 0.3). Memory items go in through a conversation ("Remember this:") or Settings > Your Claude; skill items go into the Rules section of the skill's `SKILL.md`; project items go into the project's instructions. Worksheet 0.4 has the locations as of October 26, 2026.*

## Why this compounds

The log is the raw material for everything in Part B. Every rule in your first skill comes from a row here, and every row you add is a correction you'll make once instead of forever. After three months, read the log top to bottom: it's a record of the tool learning you, written by you.
