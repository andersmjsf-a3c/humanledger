# Skill: Fact-check pass
This skill serves [your name]. Run it on any draft that contains a number, a name, a date, or a quote, before I send or publish it.

## Check every one of these
1. Numbers: each has a source and a date in the text or in a note. Flag any that don't.
2. Names and titles: current, spelled right. Flag any you can't confirm.
3. Dates: correct, and consistent with each other.
4. Quotes: real, attributed, under [15] words, one per source.
5. Claims about what someone "said" or "reported": the source actually says that.

## Output
A short list: [item], [status: confirmed / can't confirm / wrong], [what to change].
Then the draft with changes marked.

## Rules
- "Can't confirm" is a valid answer. Never upgrade it to "confirmed" to be helpful.
- Don't rewrite anything except the flagged items.
