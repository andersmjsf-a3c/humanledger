# WS 0.4. Organizing conversations, projects, and memory

Start a conversation on purpose, make one project, and see what memory carries between rooms, so you know where everything you tell the tool ends up. Thirty minutes.

## Why this matters

Chapters 11 and 12 made the argument: a conversation is a room, and nothing follows you out unless you've set up something to carry it. Three things can. Memory carries what's true about you. A project carries what's true about one body of work. A skill carries how to do one kind of task. This page sets up the first two. Part B sets up the third.

The three sorting questions from Chapter 12 are the whole method, so here they are again. Is this true about me regardless of what I'm working on? Memory. Is this about one body of work, and only that? The project. Is this about how to do one kind of task, wherever it comes up? A skill. If you ask those three questions every time you're about to tell the tool something you'll want it to keep, you'll never explain yourself from scratch again.

The trap is treating them as the same thing. Project facts in memory means every conversation about dinner knows about your Q3 pipeline. Personal preferences in a project means you repeat them in the next project. Sort first.

## Mark's example

My memory holds who I am and how I like work done: my career with dates, which email to use for which business, the "hundreds of partnerships" wording, the em-dash ban, the rule that anything in my voice gets the humanize pass. Every one of those started as a correction in a conversation and crossed over when I'd said it more than once in more than one room.

I keep two kinds of things out. Anything a stranger shouldn't see on a screen, and anything about other people that's theirs. Memory is for durable, shareable facts about how I work. It isn't a diary.

My projects are rooms with furniture. The book project's instructions say what the book is for and who it's for; its files are the outline, my notes on my own history, the glossary, and the skills that draft the chapters. Open a conversation inside it and the tool already knows all of that. The company has a different project with different furniture. When something from one belongs in the other, I carry it across on purpose, as a file. The web service I'm building got its own project the day it stopped being a book idea, and the handoff was three files and four minutes.

*How to: memory and projects, as of October 20, 2026, from the Claude help center. Memory: Settings > Memory, toggle "Generate memory from chats." Everything it remembers is listed under Topics; select one to read, edit, or delete it, or tell the tool in a chat to remember, change, or forget something and it applies from the next conversation. Sensitive topics (health, politics) are excluded unless you turn on "Include sensitive topics in memory." To keep one chat out of memory, click "+" in a new chat and turn off Memory before the first message, or use the ghost icon for an incognito chat. Turning memory off offers "Pause memory" (keeps what's saved, stops using it) or "Reset memory" (deletes everything, including project memories, permanently). Memory is on by default for Free, Pro, and Max; on Team and Enterprise an owner must enable it first. Each project has its own memory plus your account memory; "Use account memory" on the project page turns the account part off for that project. Projects: Projects in the left sidebar, "+ New Project," name and describe it, then "Set project instructions" and the "+" under project knowledge to add files; any chat started inside the project uses both. Free accounts get five projects; paid plans, unlimited. Past-chat search ("Search and reference chats" under Settings > Memory) is on paid plans only.*

## Why this compounds

The fact you gave memory in question 2 is the first line of Worksheet A1, and the project you made in question 4 is where every Part B skill gets tested. From here on, each conversation starts closer to where the last one ended, and the explaining you did this week is explaining you won't do next week.
