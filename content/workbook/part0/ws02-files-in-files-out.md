# WS 0.2. Files in, files out

Attach a document, paste a passage, and download a result, so you know what the tool can read and what it can hand back. Fifteen minutes.

## Why this matters

Most useful work starts with the tool reading something you already have: a report, a deck, a spreadsheet, a photo of a whiteboard. And most of it ends with the tool handing you something you can open somewhere else. If you've only ever typed into the box and read what came back, you've used about a third of what's there.

The habit is small: attach the thing instead of describing it. People describe a spreadsheet in three paragraphs when they could attach it in one click, and the description is always worse than the file. The tool reads PDFs, Word documents, spreadsheets, plain text, and images, and it reads them well enough to quote a page number back to you.

The other half is getting things out. A draft that lives only in the chat is a draft you'll lose. A draft downloaded as a file is yours.

## An example

*An illustration, not a real person.* Say you direct a small nonprofit and you're rebuilding the board deck from last year's. You attach four files: last year's deck, the annual report, a grant narrative, and a PDF of the budget. The tool reads all four and builds from them. It also reads the speaker notes inside last year's deck, which is how it flags a slide that mentioned a donor who asked not to be named. You'd have missed that; the notes were in the file, you'd attached the file, it read the whole file.

Going out, the new deck comes back as both a PowerPoint and a PDF. You open the rendered PDF before it goes to anyone, because the rendered file is what the board sees and the chat's description of it is not.

The thing most people don't know in their first month: it reads images. A photo of the whiteboard after the planning meeting, attached, comes back as a typed list of what was on the board.

*How to: attaching and downloading, as of October 26, 2026. In the chat box there's a "+" (or a paperclip) for attaching files; you can also drag a file onto the chat or paste text directly. The tool reads PDFs, Word documents, spreadsheets, plain text, code, and images, within size limits that change; if a file is refused, split it or paste the part you need. Anything it builds opens in a panel beside the chat; documents and decks there have an Export control; everything it builds is also saved to the Artifacts tab in the sidebar. Creating files requires "Code execution and file creation" to be on under Settings > Capabilities. All plans can attach files and create them.*

## Why this compounds

Every worksheet in Part B starts by attaching something real: last week's report, your brand guide, a draft. Once attaching is a reflex, the tool is working on your actual material instead of your description of it, and every skill you build in Part B is tested on real files from day one.
