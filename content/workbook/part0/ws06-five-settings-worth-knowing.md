# WS 0.6. Five settings worth knowing

A dated table of the five settings that change what the tool does for you, checked once so you stop wondering why it behaved differently today. Ten minutes.

## Why this matters

Most of what people blame on the tool is a setting. It didn't search the web because search was off for that chat. It didn't remember because memory was paused. It gave a shallower answer because a faster model was selected. It couldn't make a file because file creation wasn't turned on. None of those is the tool being bad at the job. All of them are a toggle.

Five settings account for nearly every "it worked yesterday" I've heard, so this page is a table and a check. Go through it once. Then, when something behaves oddly, come back here before you blame yourself or the machine.

Chapter 11 warned that these move. The table has a date on it. If the date is old, the names may have changed; the setting itself almost certainly still exists, so ask the tool where it is now.

## Mark's example

The setting that cost me the most was web search, early on. I'd ask for a figure, get a confident number, and only later work out that search had been off and the number came from the model's memory of the world, with the world itself never consulted. Now I check the slider when a fact matters, and Chapter 6's pass assumes search is on.

The one I changed most recently was model choice. For a year I ran the strongest model for everything. I still do for judgment work: drafting, arguing, anything with a reader who matters. For routine summaries I've moved down a tier, because the wait and the usage limit started to cost me more than the difference in quality. The right setting changes with the job in front of you.

## Why this compounds

You've turned five mysteries into five known switches. From now on, a strange answer costs you thirty seconds of checking instead of an afternoon of doubt, and when Chapter 11's next change arrives, you'll know which switch to look for instead of relearning the tool.
